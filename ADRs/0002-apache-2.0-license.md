# ADR-0002: Apache License 2.0 for UniImage

- Status: Accepted
- Date: 2026-07-15
- Scope: UniImage

## Decision

UniImage is distributed under Apache-2.0. The integrated `nim-exif` work is
also Apache-2.0. NimContracts remains an external MIT-licensed dependency;
the repository does not vendor its source.

The repository ships `LICENSE`, `NOTICE`, and `CONTRIBUTING.md` with DCO
requirements. `NOTICE` records the source provenance and external dependency.
